# 紫苏叶瓶颈选股（独立模块）

基于"紫苏叶逻辑 + bottleneck-hunter skill 模板"的独立选股看板工具，与原选股/模拟盘系统完全分开：

- **不改动**项目任何代码、数据与自选股；
- **只读复用**项目的取数模块（`research_data` 行情/财务、`market_snapshot` 活跃池截面、本地缓存）；
- 输入是"研究底稿"（bottleneck-hunter 产出），输出全部在本模块 `输出/` 目录。

## 使用流程

### 第 1 步：产出研究底稿

把想研究的方向（如"固态电池产业链""AI算力-光通信"）发给 Codex，附言：

> 按 bottleneck-hunter skill 执行，输出 JSON 研究底稿，格式参照 紫苏叶选股/研究底稿模板.json

底稿包含：超级趋势确认、瓶颈环节（S/A/B 评级 + 6 条判定 + TAM）、候选 A 股（代码/份额/交叉验证/催化剂/风险）、反证清单。

### 第 2 步：运行脚本

```bat
python 紫苏叶选股\bottleneck_picker.py 紫苏叶选股\样例\ai光通信样例底稿.json
```

可选参数：

- `--topic 主题名`：覆盖报告标题；
- `--outdir 目录`：自定义输出目录（默认 `紫苏叶选股/输出/`）；
- `--export-watch 清单.txt`：导出候选代码清单（**不会直接修改项目自选股.txt**，核对后手动添加）。

### 第 3 步：看结果

`紫苏叶选股/输出/` 下生成三件套：

- `*_瓶颈机会看板_YYYYMMDD.html`：网页看板（趋势确认/瓶颈地图/机会排名表/标的一页纸/反证清单/行动建议）
- `*_瓶颈机会看板_YYYYMMDD.md`：Markdown 报告（skill 模板，可存档/转发）
- `*_结果_YYYYMMDD.json`：机器可读结果

## 评分规则（与 bottleneck-hunter 模板一致）

- 瓶颈评级：6 条判定（供给集中/扩产周期/替代难度/产能利用率/需求增速/客户验证）红项 ≥4=S、3=A、1-2=B；
- 估值红黄绿灯：市值>TAM 20%、PS>30x 且增速<100%、市值>5年乐观收入10倍 → **红灯（信号强度封顶★★）**；亏损+PS>15x、PE>80x → 黄灯；PS<10x 且增长 → 绿灯；
- 安全边际粗算：10 年 25x PE 退出年化回报（亏损股标注不可算）；
- 结论：值得深入研究 / 加入观察 / 暂不追踪 / ⚠估值透支。

## 重要边界

- 瓶颈真实性（供给集中度、客户名单、扩产周期等）**无法从免费行情接口自动取得**，必须来自研究底稿，并需用公告/认证/客户验证持续核验；
- 财务与行情来自东财/腾讯免费接口（单源未双源核验），断网时自动使用本地缓存并在报告标注；
- 本工具只做研究与筛选展示，**不构成任何投资建议**。
