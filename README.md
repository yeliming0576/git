## 选股规则（v2 优化版）

热门股不再用“单日排名线性打分”，改为：

1. **热度评分**：成交量/成交额/换手率三榜，指标先做市值中性化（成交额÷流通市值、量÷流通股本），取对数后按榜内 Z-score 标准化求和；
2. **热度持续性**：每天自动缓存各榜排名（`排名历史.json`），综合最近 5 日的排名稳定性与上升趋势（今日 50% + 稳定性 30% + 趋势 20%）；
3. **自适应过滤**：股价上限 = 全市场股价中位数×2.5（不低于 12 元）；当日换手/成交活跃度需高于该股过去 20 日的第 20 分位；换手率 <1% 直接淘汰；
4. **市场环境过滤**：中证全指收盘必须站上 MA20 且 MA20>MA60，否则降仓（只保留 1 只观察）；
5. **行业分散**：入选股票尽量分属不同行业（东财申万行业），同行业候选占比 >40% 时给出拥挤度预警；
6. **单股分析**：趋势评分改为三维度 6 分制（趋势方向/动量确认/量能配合），RSI/KDJ 只做超买超卖标签；回测加入 0.15% 单边交易成本、回撤按持仓期间盘中最高价计算；止损用 2 倍 ATR 动态调整。

参数都在 `selection.py` 和 `quant_engine.py` 文件顶部，想调整直接改。

配套工具：`python backtest_grid.py 600519` 可做参数敏感性网格测试和样本外验证。

## 常见问题

- **数据存哪里？** 历史数据保存在 `数据\选股数据.db`（SQLite 单文件数据库）与 `数据\journal.db`（模拟盘账本），排名/热门股缓存也在 `数据\`；数据库不可用时自动回退到 JSON，不影响运行。
- **报告文件越来越多怎么办？** 每日报告在 `报告归档\每日\`，组合/个股报告分别在 `报告归档\组合\`、`报告归档\个股\`；超过 30 天的报告会自动压缩进 `报告归档\YYYY-MM.zip` 并删除原件，文件夹不会无限膨胀。
- **日志在哪？** 自动运行日志在 `日志\自动运行日志.txt`。

- **报告能打开但图表空白**：图表库已内置（echarts.min.js，请勿删除）；若仍空白请检查网络，页面会自动回退到 CDN。
- **提示抓取失败**：行情接口偶尔限流，程序会自动重试，稍后再运行即可。
- **端口被占用**：命令行运行 `python report_server.py --port 9000`。
- **想换数据源**：项目内置 `eastmoney.py` 备用模块，与技能版返回结构一致。

## 个股量化分析（v2 规范）

按《A股个股量化分析规范_v2.md》实现：

- **数据**：腾讯后复权 8 年（回测）/ 前复权（展示），沪深300 基准；
- **特征**：F1 趋势斜率 / F2 相对强度 / F3 动量分位 / F4 波动状态 / F5 量价配合；
- **决策**：L1 可交易性 → L2 趋势门槛 → L3 择时评分（0~100），输出 强势可入 / 强势观望 / 弱势 / 风险警示；
- **交易**：ATR 初始止损 + 吊灯止损、次日开盘执行、涨跌停不可成交建模、固定 1% 风险仓位、盈亏比≥2 过滤；
- **回测**：Walk-forward（3年训练/1年测试）+ 参数网格 + 随机对照 + 基准对比；N<30 标注"样本不足"；
- **数据源局限（已在报告中声明）**：截面分位暂以个股自身 8 年时序分位替代（全市场数据需 Tushare Pro）；免费接口无退市股池，存在幸存者偏差。

## 组合与执行（模拟盘，按《组合与执行规范》）

- **选股链路 L0~L6**：股票池（榜单+自选代理）→ L1 可交易性 → L2 趋势门槛 → L3 因子排序 → **L4 热度负向剔除**（5日涨幅/换手>95分位、3日两涨停即剔除——热度从入口筛选改为出口排除）→ L5 行业中性 → L6 前 15~20 只；
- **组合构建**：风险预算定仓（单票 1% 风险、10% 上限、组合总风险 6%、单行业 30%、总仓位 70%、容量≤20日均成交额1%）；
- **调仓执行**：卖出优先 → 买入，`is_tradable()` 涨跌停/停牌预检回测与实盘同一份代码；T 日信号、T+1 开盘执行；
- **三级风控**：L1 个股（2ATR止损/吊灯/跳空）→ L2 组合（单日亏2%暂停、风险6%减仓、行业35%强制）→ L3 熔断（回撤15%清仓、连亏8笔降半仓、信号偏离20%停机）；
- **日志绩效**：`journal.db`（trades/daily_nav/signal_log/pending_orders）+ 月度 Beta/Alpha/t 归因 + 一致性指标；
- **运行**：`python paper_trade.py` 生成 `组合与执行报告.html`；当前为模拟盘（过渡期≥3个月），不连接券商。

> 规范内部矛盾修正（已在代码注释注明）：目标=入场+3ATR、止损=入场−2ATR 时盈亏比恒为 1.5<2，永远无法通过"盈亏比≥2"过滤；按规范意图将目标位改为 4×ATR（=2:1）后过滤可执行。
